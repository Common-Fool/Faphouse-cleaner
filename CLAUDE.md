# Правила для Claude

- Изменения коммитить и сразу пушить в `main`, не спрашивая. Не оставлять отдельные ветки и не открывать PR без явной просьбы.
- При изменении скрипта поднимать `@version` в `faphouse-cleaner.user.js`, иначе автообновление не сработает.
- Классы и id скрипта — только с префиксом `fhc-`: сам сайт использует `fh-` (например, `.fh-modal`), и пересечения ломают страницу.
